# 🎮 huEVO for Xbox 360 Homebrew

> **Нативный автономный клиент независимой ретро-соцсети [huEVO](https://huevo.su) для Microsoft Xbox 360 (Freeboot / RGH / JTAG / Aurora Dashboard)**
> **Работает НАПРЯМУЮ через проводной интернет (Ethernet) или Wi-Fi консоли. Компьютер или мост НЕ требуются!**


---

## 🌟 Главные преимущества

* **100% Автономность**: консоль связывается с сервером `huevo.su` напрямую через свой сетевой провод Ethernet по порту 443 (HTTPS/TLS). Никаких сторонних программ на ПК или телефоне запускать не нужно.
* **Вход в аккаунт прямо с консоли**: во вкладке *Профиль* вы можете войти под своим логином и паролем от `huevo.su`.
* **Нативная экранная клавиатура Xbox 360 (`XShowKeyboardUI`)**: ввод текста постов, комментариев и паролей через оригинальную системную клавиатуру Xbox 360 (поддерживаются русский язык, геймпад, Chatpad и USB-клавиатуры).
* **Стена и Лента (Feed)**: просмотр записей, счетчики лайков и комментариев, публикация на стену прямо с геймпада по нажатию `(X)`.
* **Ретро Аудио-плеер**: музыкальный плеер с ностальгическим эквалайзером в стиле Xbox 360 Blades Dashboard.
* **Полная интеграция с Aurora Dashboard**: запуск в 1 клик через `default.xex`, чистый выход в дашборд по кнопке `Back`.

## 🕹 Управление геймпадом Xbox 360

| Кнопка | Действие |
| :--- | :--- |
| **D-Pad / Левый Стик** | Навигация по карточкам постов и меню (с плавной авто-прокруткой) |
| **(A)** | Выбрать / Поставить лайк / Включить трек / Войти в аккаунт |
| **(B)** | Назад |
| **(X)** | Написать новую запись на стену (вызов экранной клавиатуры) |
| **(Y)** | Обновить ленту / Поставить лайк |
| **(LB) / (RB)** | Быстрое переключение вкладок: *Лента* ↔ *Профиль* ↔ *Сообщения* ↔ *Музыка* ↔ *Настройки* |
| **Back / Guide** | Безопасный возврат в Aurora Dashboard |

## 🚀 Установка на Xbox 360 (Aurora Dashboard)

### 1. Копирование на консоль:
1. Подключитесь к Xbox 360 по **FTP** либо скопируйте файлы через **USB-флешку (FAT32)**.
2. Поместите папку на внутренний жесткий диск консоли:
   ```text
   Hdd1:\Homebrew\huEVO\
   ```
   Внутри должны находиться:
   ```text
   Hdd1:\Homebrew\huEVO\
   ├── default.xex         # Исполняемый файл Xbox 360
   └── assets\
       ├── icon.png        # Иконка для Aurora
       └── banner.png      # Широкоформатный баннер для Aurora
   ```

### 2. Запуск в Aurora:
* В меню **Aurora Dashboard** обновите пути сканирования (`Scan Paths`).
* Плитка **huEVO** появится в категории **Homebrew** с официальной иконкой и баннером.
* Убедитесь, что к консоли подключен проводной интернет (Ethernet) или настроен Wi-Fi.
* Запустите приложение — оно сразу подключится к `huevo.su`!

## 🛠 Сборка из исходников (Visual Studio / XDK)

1. Откройте [`huEVO.sln`](file:///Users/neriusneriusnerius/Desktop/xbox360%20huEVO%20homebrew/huEVO.sln) в **Visual Studio 2010** с установленным **Xbox 360 SDK (XDK 21256.x)**.
2. Выберите конфигурацию `Release | Xbox 360`.
3. Соберите проект (`Ctrl + Shift + B`).
4. Готовый файл `default.xex` скомпилируется в папку `bin/Release/default.xex`.
